# Third-party notices

Adaptive UI Engine uses the following open-source components. Licences are as
published on PyPI (checked 26 November 2026). Builds made with PyInstaller
bundle these libraries; keep this file with every download.

| Component | Used for | Licence |
| --- | --- | --- |
| [customtkinter](https://pypi.org/project/customtkinter/) | Desktop UI widgets | CC0 1.0 Universal |
| [pynput](https://pypi.org/project/pynput/) | Global keyboard and mouse listeners, pause hotkey | LGPL-3.0 |
| [pystray](https://pypi.org/project/pystray/) | System tray icon | LGPL-3.0 |
| [Pillow](https://pypi.org/project/pillow/) | Tray icon and colour-field rendering | MIT-CMU |
| [screen-brightness-control](https://pypi.org/project/screen-brightness-control/) | Brightness effects (Windows, Linux) | MIT |
| [plyer](https://pypi.org/project/plyer/) | Desktop notifications | MIT |
| [screeninfo](https://pypi.org/project/screeninfo/) | Monitor geometry for overlays | MIT |
| [psutil](https://pypi.org/project/psutil/) | CPU and memory figures (Phase 3 drawer) | BSD-3-Clause |
| [pywinstyles](https://pypi.org/project/pywinstyles/) | Windows 11 Mica / acrylic (Windows only) | CC0 1.0 Universal |
| [pyobjc-framework-Cocoa](https://pypi.org/project/pyobjc-framework-Cocoa/) | Cursor, foreground app, overlays (macOS only) | MIT |
| [python-xlib](https://pypi.org/project/python-xlib/) | Cursor, foreground app, overlays (Linux X11 only) | LGPL-2.0-or-later |
| [PyInstaller](https://pypi.org/project/pyinstaller/) | Building the downloads (not shipped as a library) | GPL-2.0 with bootloader exception |

LGPL components are used unmodified as separately installable Python packages.
